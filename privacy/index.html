Política de privacidad

Última actualización: 28 de septiembre de 2026.

Esta política explica de forma general cómo NeXA ODVIA trata la información cuando una persona utiliza sus aplicaciones y servicios.

1. Alcance

NeXA ODVIA es una solución de gestión orientada a la práctica odontológica. Las funciones disponibles pueden variar según la versión instalada y las integraciones activadas.

2. Información tratada

Dependiendo de las funciones utilizadas, la aplicación puede tratar información introducida por el usuario para la gestión de su práctica. NeXA ODVIA no vende información personal.

3. Datos clínicos y de pacientes

La persona o entidad usuaria es responsable de contar con las autorizaciones y bases legales necesarias para ingresar y tratar información de pacientes.

4. Google Calendar

Cuando el usuario decide conectar Google Calendar, NeXA ODVIA solicita los permisos necesarios para las funciones de calendario habilitadas. El acceso puede revocarse desde la cuenta de Google del usuario.

La información obtenida mediante las API de Google se utiliza únicamente para proporcionar las funciones visibles de integración solicitadas por el usuario y no se vende a terceros.

5. Servicios de terceros

Algunas funciones pueden depender de proveedores externos, sujetos a sus propios términos y políticas.

6. Seguridad

Se aplican medidas razonables orientadas a proteger la información frente a acceso, alteración o divulgación no autorizados.

7. Conservación y eliminación

La conservación depende del tipo de dato, configuración y obligaciones aplicables. El usuario puede solicitar soporte sobre información gestionada por servicios controlados directamente por NeXA ODVIA.

8. Cambios

Esta política puede actualizarse para reflejar cambios técnicos, legales o funcionales.

9. Contacto

Las consultas de privacidad se canalizan mediante la página de Soporte.

Importante: antes del lanzamiento comercial final, este texto debe revisarse para que refleje exactamente la arquitectura, almacenamiento, permisos y flujos de datos de la versión publicada.
