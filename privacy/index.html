Política de privacidad

Última actualización: 4 de octubre de 2026.

Esta Política de Privacidad describe cómo NeXA ODVIA accede, utiliza, almacena y comparte información cuando una persona utiliza la aplicación y, en particular, cuando decide conectar su cuenta de Google para utilizar la integración con Google Calendar.

1. Identidad y alcance

NeXA ODVIA es una solución de gestión para la práctica odontológica. Sus funciones pueden incluir gestión de pacientes, agenda, citas, documentación clínica y administrativa e integraciones opcionales con servicios de terceros. Esta política se aplica a la aplicación NeXA ODVIA y a las funciones disponibles desde el dominio oficial nexaodvia.com.

2. Información que el usuario introduce en NeXA ODVIA

Dependiendo de las funciones utilizadas, el usuario puede introducir información de pacientes, citas, tratamientos, fotografías, documentos, datos administrativos, financieros u otra información necesaria para gestionar su práctica odontológica. La persona o entidad que utiliza NeXA ODVIA es responsable de contar con las autorizaciones, consentimientos y bases legales necesarias para tratar información de pacientes y de cumplir las obligaciones profesionales, de confidencialidad y protección de datos que le correspondan.

3. Datos de Google a los que accede NeXA ODVIA

La conexión con Google Calendar es opcional y solo se activa cuando el usuario la autoriza mediante el flujo OAuth de Google. Para ofrecer la sincronización de agenda, NeXA ODVIA puede acceder a datos de eventos de Google Calendar necesarios para esa función, tales como:

  • identificador del calendario y del evento;
  • título o resumen del evento;
  • fecha y hora de inicio y finalización;
  • descripción, ubicación y estado del evento cuando estén presentes;
  • información relacionada con cambios, actualizaciones o eliminación del evento;
  • otros campos del evento únicamente cuando sean necesarios para mostrar, crear, actualizar o sincronizar la cita solicitada por el usuario.

NeXA ODVIA solicita el alcance de Google Calendar necesario para ver y editar eventos. No solicita permisos para administrar la cuenta de Google del usuario ni para acceder a servicios de Google que no sean necesarios para la función de calendario.

4. Cómo utiliza NeXA ODVIA los datos de Google Calendar

Los datos obtenidos mediante Google Calendar se utilizan exclusivamente para proporcionar funciones visibles y solicitadas por el usuario, incluyendo:

  • mostrar en NeXA ODVIA los eventos necesarios para la agenda;
  • crear en Google Calendar una cita generada por el usuario desde NeXA ODVIA;
  • actualizar fecha, hora u otros datos de una cita cuando el usuario los modifica;
  • eliminar o cancelar un evento cuando el usuario realiza esa acción desde la función de agenda;
  • mantener correspondencia entre una cita de NeXA ODVIA y su evento de Google Calendar para evitar duplicados y permitir la sincronización.

NeXA ODVIA no utiliza los datos obtenidos de Google Calendar para publicidad, creación de perfiles publicitarios, venta de datos, evaluación crediticia ni entrenamiento de modelos de inteligencia artificial.

5. Almacenamiento y conservación

NeXA ODVIA está diseñada principalmente como una aplicación de escritorio para la gestión de la práctica. La información necesaria para mantener la integración —por ejemplo, credenciales de autorización OAuth, identificadores de eventos y datos de sincronización— puede almacenarse localmente en el dispositivo del usuario para conservar la sesión y vincular las citas con Google Calendar.

Los datos se conservan únicamente durante el tiempo necesario para proporcionar las funciones solicitadas por el usuario, cumplir obligaciones aplicables o mientras la integración permanezca habilitada. El usuario mantiene el control sobre la información almacenada localmente y sobre sus propios mecanismos de respaldo.

6. Compartición y transferencias

NeXA ODVIA no vende datos personales ni datos obtenidos mediante las API de Google. Los datos de Google no se comparten con terceros para fines publicitarios o comerciales independientes.

La información solo puede comunicarse cuando sea estrictamente necesario para proporcionar la función solicitada por el usuario, cumplir una obligación legal, proteger la seguridad del servicio o cuando exista consentimiento explícito del usuario. El personal o desarrollador de NeXA ODVIA no accede al contenido de Google Calendar del usuario de forma rutinaria. Cualquier acceso humano excepcional para soporte requerirá autorización del usuario, salvo cuando sea necesario por motivos de seguridad o cumplimiento legal.

7. Cumplimiento de las políticas de Google

El uso y la transferencia por parte de NeXA ODVIA de la información recibida de las API de Google se adherirá a la Google API Services User Data Policy, incluidos sus requisitos de Limited Use.

NeXA ODVIA limita el uso de los datos de Google a proporcionar o mejorar la función de sincronización de calendario que el usuario puede ver y utilizar directamente dentro de la aplicación.

8. Seguridad

La autorización con Google se realiza mediante OAuth 2.0. Las comunicaciones con los servicios de Google utilizan conexiones cifradas provistas por Google. NeXA ODVIA aplica medidas razonables para proteger credenciales, tokens y datos de sincronización frente a acceso, alteración o divulgación no autorizados. Ningún sistema informático puede garantizar seguridad absoluta.

9. Control del usuario y revocación del acceso

El usuario puede dejar de utilizar la integración de Google Calendar en cualquier momento. También puede revocar el acceso de NeXA ODVIA desde la sección de seguridad y aplicaciones conectadas de su Cuenta de Google. Al revocar la autorización, NeXA ODVIA deja de poder acceder a nuevos datos de Google Calendar con esa autorización.

La revocación del acceso a Google no elimina automáticamente la información que el usuario haya decidido conservar localmente dentro de su instalación de NeXA ODVIA. Esa información permanece bajo control del usuario y puede eliminarse desde los mecanismos disponibles en la aplicación o en su almacenamiento local.

10. Eliminación de datos y solicitudes de privacidad

El usuario puede solicitar información relacionada con sus datos o con la integración de Google mediante la página oficial de Soporte. Cuando una solicitud corresponda a información controlada directamente por NeXA ODVIA, se atenderá de acuerdo con las obligaciones legales aplicables. Los datos que residan exclusivamente en el dispositivo o infraestructura del propio usuario deberán gestionarse desde ese entorno.

11. Servicios de terceros

Algunas funciones pueden depender de servicios de terceros. Google Calendar y el sistema de autorización de Google están sujetos también a los términos y políticas de Google. NeXA ODVIA no controla las prácticas independientes de esos proveedores.

12. NeXA Bridge, NeXA Chair y dispositivos autorizados

NeXA puede utilizar dispositivos Android autorizados como componentes complementarios denominados Bridge, Chair o una combinación de ambos. La autorización y las capacidades efectivas son determinadas por NeXA Core. Estos dispositivos no están diseñados para sustituir a NeXA Core como fuente principal de la historia clínica.

Dependiendo de la función habilitada, un dispositivo autorizado puede recibir temporalmente información operativa o clínica necesaria para completar una tarea visible para el usuario. NeXA procura limitar esa información al mínimo necesario y eliminar datos temporales cuando dejan de ser necesarios, cuando una solicitud se cancela o expira, cuando se revoca un dispositivo o cuando finaliza una sesión clínica.

13. WhatsApp y servicios de accesibilidad

NeXA Bridge puede ofrecer funciones de comunicación mediante WhatsApp Personal o WhatsApp Business. Cuando Android AccessibilityService se utilice para asistir un flujo de recordatorios, su finalidad debe limitarse a una secuencia determinística configurada y autorizada por el usuario del consultorio.

NeXA no utiliza AccessibilityService con el propósito de actuar como una herramienta general de accesibilidad ni para navegar de forma libre por otras aplicaciones. Si la interfaz de WhatsApp no puede verificarse de forma segura, el modo automático debe detenerse y requerir un flujo supervisado o una actualización compatible. Consulta la explicación específica en Uso de servicios de accesibilidad.

14. Información clínica y datos sensibles

La información odontológica, fotografías clínicas y otros datos de salud pueden constituir información personal sensible. El consultorio o profesional que utiliza NeXA es responsable de definir la base jurídica, conservación, acceso y uso de esa información conforme a sus obligaciones profesionales y a la normativa aplicable. NeXA está diseñada para apoyar ese tratamiento sin convertir los dispositivos complementarios en repositorios clínicos independientes.

15. Cambios en esta política

Esta Política de Privacidad puede actualizarse para reflejar cambios técnicos, funcionales o legales. La fecha de la versión vigente se mostrará al inicio de esta página. Si se introducen cambios materiales en la forma en que se utilizan los datos, la política se actualizará antes de aplicar esas nuevas prácticas cuando corresponda.

16. Contacto

Para consultas de privacidad, soporte o solicitudes relacionadas con el tratamiento de datos, utiliza la página oficial de Soporte de NeXA ODVIA o el correo de contacto indicado en la pantalla de consentimiento de Google OAuth.

NeXA ODVIA y Google Calendar: la integración es opcional. El usuario decide si conecta su cuenta de Google y puede revocar la autorización cuando lo desee.
